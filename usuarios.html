Volver al menu
Para cada HTML nuevo del menú, agregar en el head: <script src="menu-auth-guard.js?v=20260710-guard4" data-menu-guard="id_del_boton"></script>. El data-menu-guard tiene que coincidir con el botón/permisos de este panel.
Botones visibles
Clic izquierdo: rojo, acceso normal. Clic derecho: verde, acceso con edición. Repetí el mismo clic para quitarlo.
